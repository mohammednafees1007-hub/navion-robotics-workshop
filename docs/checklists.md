# Printable workshop checklists
## Before power
- [ ] Inventory complete; mechanical fasteners verified by teacher
- [ ] Battery off; common ground; 3.3 V sensor outputs confirmed
- [ ] Teacher approves regulator assumption and USB power isolation
- [ ] ENA/ENB motor jumpers removed; regulator jumper checked separately
- [ ] Wheels raised, wires clear, switch reachable
## Per experiment
- [ ] Correct sketch and pin map
- [ ] Stop behavior checked
- [ ] Polarity/direction calibrated
- [ ] Low-speed supervised floor test
- [ ] Observation logged; change explained
