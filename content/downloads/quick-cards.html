Quick start

  1. Start here: A Windows 10/11 laptop, your robot kit and a teacher for hardware checks.
  2. Check the parts: The kit laid out on a clear table. Keep cells with the teacher.
  3. Assemble the chassis: Chassis, motors, clamps, wheels, caster, boards, holder, screwdriver and teacher-approved fasteners.
  4. Install Arduino on Windows: Windows 10/11 laptop, internet for installation, ESP32 and data cable. Battery OFF; external ESP32 5 V lead disconnected.
  5. Upload your first USB test: IDE installed, board/port selected, USB only, motor battery OFF and external 5 V isolated.
  6. Wire the base robot: USB test passed; battery and USB disconnected; teacher present; readable pin labels.
  7. Check motor direction & stop: Base wiring approved; wheels lifted; remote sketch downloaded; teacher-approved test power arrangement.

Change mode / shut down

  1. Switch motor battery OFF. Unplug USB before changing wires or mounts.
  2. Teacher isolates external ESP32 5 V before USB upload.
  3. Upload the selected sketch. Carry over measured motor inversion and calibrated sensor polarity.
  4. Unplug USB before restoring approved battery-only power. Teacher checks wiring, clear space and stop behavior before a run.
  5. Finish with battery OFF; store cells as directed by the teacher.
