Plain-language glossary

TermWhat it means here
ESP32The microcontroller that runs one uploaded program at a time.
GPIOA numbered signal pin. GPIO number is not the physical row position.
GND / common groundShared voltage reference between board, driver and sensors.
H-bridge / L298NThe driver switches motor current and direction; ESP32 pins only send control signals.
PWM / dutyFast power switching. SPEED=145 is duty out of 255, not motor RPM or a measured voltage.
Digital IR sensorA reflected-light threshold output, HIGH or LOW. It does not report exact distance.
Active levelThe measured HIGH/LOW value that the program interprets as black or an obstacle.
USB COM / Bluetooth COMDifferent Windows serial connections. The wireless port requires Classic SPP support.
Verify / UploadCompile source / send the compiled program to the board.
setup() / loop()Run initialization once / repeat decision logic.
millis() / delay()Measure elapsed time / pause processing. The remote timeout uses millis().
DeadmanStop if movement commands are not refreshed within the allowed time.

Read the motor function

drive(left,right) takes signed PWM values. Positive means forward after your inversion calibration, negative means reverse, and zero means stop. It calls oneMotor() for each side, clears PWM before changing direction and then applies the new duty.

Where to edit safely

const int SPEED=145;
const bool INVERT_LEFT=false, INVERT_RIGHT=false;
const int DETECTED_LEVEL=LOW; // only if your measurements confirm it

Edit one setting at a time near the top of the relevant sketch. Save, Verify and Upload after each change. Every robot .ino is self-contained; changing one does not automatically update the others. Do not change the GPIO map in just one place without updating the wiring and documentation.
