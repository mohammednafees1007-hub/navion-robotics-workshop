Install on Windows 10/11

  1. Download Arduino IDE 2.x from Arduino and run its installer.
  2. In File → Preferences add https://espressif.github.io/arduino-esp32/package_esp32_index.json to Additional Boards Manager URLs.
  3. Open Boards Manager, search esp32, install “esp32 by Espressif Systems”. These sketches target core 3.x and use pin-based LEDC APIs.
  4. Connect a data-capable cable. If no COM port appears, inspect Windows Device Manager and install the official CP210x driver if needed.
  5. Select ESP32 Dev Module and the COM port that appears when you plug in the board.

Hello without an LED

void setup() { Serial.begin(115200); }
void loop() { Serial.println("Hello, engineer!"); delay(1000); }

Upload with battery disconnected. At 115200 baud you should see one message each second. This exercise does not assume an onboard LED exists.

REAL SCREENSHOT PLACEHOLDER: Arduino IDE board, port and Serial Monitor.

If upload fails

Check data cable, port, board, driver, and that no terminal has the port open. If the exact board requires it, hold BOOT during connection and release after upload starts. Ask the teacher if this fails; do not randomly change wiring while powered.
